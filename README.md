## What the paper does

A³ is a post-training low-rank approximation framework for Transformer layers. It separates a layer into three functional components and chooses reduced dimensions using the component's activations rather than applying an unstructured low-rank factorization to an entire weight matrix:

- **A³-QK** approximates the query-key score function with an activation-aware, autocorrelation-weighted truncated SVD. For RoPE and GQA, the implementation uses structured column-pair or group-wise CUR-style reductions where the plain SVD assumptions do not apply.
- **A³-OV** approximates the value-output path using the autocorrelation of the attended value representation; the released implementation exposes `axkv` and related baselines.
- **A³-MLP** reduces intermediate channels using weighted channel scores. The weight-aware `rxx-w` route uses both activation statistics and output weights; `rxx` is an ablation/baseline.

The authors' end-to-end workflow is explicit:

```text
calibration text + original model
              │
              ▼
collect Rxx statistics  ──►  approx compressed state dictionaries  ──►  eval PPL / lm-eval / profiling
```

The official code collects statistics from 128 random 2048-token SlimPajama sequences for the main setup, uses BF16 model computation with FP64 accumulation for autocorrelation matrices, then evaluates on WikiText-2, C4, SlimPajama, and downstream `lm-eval` tasks. The paper reports experiments on H100/A100 systems; those resources and model checkpoints are not included in this repository.

### Re-running the official pipeline

The commands below are the documented shape of the official workflow. They require the authors' environment, compatible model weights, datasets, and enough accelerator memory; they are not claimed to run in this small audit workspace.

```bash
conda env create -f environment.yaml
conda activate a3
pip install -r requirements.txt

cd experiments/llm
python run.py --config configs/<model>.yaml collect --output_dir <stats-dir>
python run.py --config configs/<model>.yaml approx --qk_rxx_dict <stats-file> --vo_rxx_dict <stats-file> --ffn_rxx_dict <stats-file>
python run.py --config configs/<model>.yaml eval ppl --qk_state_dict <qk-file> --vo_state_dict <vo-file> --ffn_state_dict <ffn-file>
python run.py --config configs/<model>.yaml eval harness --tasks "['a3-classic']" --qk_state_dict <qk-file> --vo_state_dict <vo-file> --ffn_state_dict <ffn-file>
```

The actual flags depend on the model architecture and the component being approximated. Read the pinned [`docs/llm.md`](https://github.com/DeepWok/a3/blob/f688fc5d270ea9185fe29ea656bf168f0fab787a/docs/llm.md) and the selected configuration before launching a run.

### Claim 5 finite conformance toy

[`src/claim5_a3_conformance.py`](src/claim5_a3_conformance.py) implements the three algebraic routes on non-isotropic synthetic matrices with `d=12`, rank `r=4`, and fixed seeds `11, 23, 47, 89, 131`. It compares the activation-aware method with predeclared negative controls:

| Component | Method | Mean relative error |
| --- | --- | ---: |
| QK | activation-aware weighted SVD | `0.1033238568` |
| QK | raw SVD control | `0.2785479061` |
| OV | autocorrelation-weighted SVD | `0.1361070573` |
| OV | raw SVD control | `0.2860748917` |
| MLP | retained-energy channel selection | `0.2948223031` |
| MLP | low-energy control | `0.9579855232` |

These values only show that the finite implementation follows the stated matrix routes on the declared fixture. They do not establish a universal theorem, reproduce a LLaMA result, or validate the paper's benchmark tables. Checked-in CSV, configuration, log, and summary files are listed in [`outputs/claim5_a3_conformance/SHA256SUMS`](outputs/claim5_a3_conformance/SHA256SUMS).

Run the toy independently into a temporary directory:

```bash
python3 src/claim5_a3_conformance.py \
  --out "$(mktemp -d)/claim5_a3_conformance" \
  --seeds 11 23 47 89 131
```

Verify the committed evidence without changing it:
